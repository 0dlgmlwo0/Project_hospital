
# 🏥 MedicalSubject API 연동 구조 및 설명

## 📁 폴더 트리 구조

```
📁 src
 └── 📁 main
     └── 📁 java
         └── 📁 com
             └── 📁 hospital
                 ├── 📁 async
                 │   └── MedicalSubjectAsyncRunner.java
                 │
                 ├── 📁 client
                 │   └── MedicalSubjectApiCaller.java
                 │
                 ├── 📁 controller
                 │   └── MedicalSubjectController.java
                 │
                 ├── 📁 dto
                 │   └── 📁 api
                 │       ├── MedicalSubjectApiResponse.java
                 │       └── MedicalSubjectApiItem.java
                 │
                 ├── 📁 entity
                 │   └── MedicalSubject.java
                 │
                 ├── 📁 parser
                 │   └── MedicalSubjectApiParser.java
                 │
                 └── 📁 repository
                     └── MedicalSubjectRepository.java
```

## 📄 파일별 기능 설명

| 파일명 | 설명 |
|--------|------|
| `MedicalSubjectAsyncRunner.java` | 병원별 API 호출, JSON 파싱 후 DB 저장. 비동기 처리 |
| `MedicalSubjectApiCaller.java` | 공공 API 호출하여 진료과목 JSON 수신 |
| `MedicalSubjectApiResponse.java` | 공공 API 응답 전체 구조 매핑 DTO |
| `MedicalSubjectApiItem.java` | API의 실제 데이터 항목 DTO |
| `MedicalSubjectApiParser.java` | 응답 데이터 파싱 및 과목 정규화 |
| `MedicalSubjectRepository.java` | DB 저장/조회 위한 JPA Repository |
| `MedicalSubject.java` | 진료과목 Entity 정의 (hospitalCode, subjectName 포함) |
| `MedicalSubjectController.java` | `/subject/save`, `/subject/status` API 컨트롤러 |

## 🔁 전체 동작 흐름

1. `/subject/save` 호출
2. Controller → Service → AsyncRunner 실행
3. 병원코드별 API 호출 → JSON 파싱 → 정제된 과목 저장
4. `/subject/status` 로 상태 확인 가능
